# Projeto Banco de Dados - Suicídios (2010-2019)

## Descrição
Projeto desenvolvido na disciplina de Banco de Dados com base em dados do DATASUS.

## Objetivo
Analisar dados de suicídios no Brasil entre 2010 e 2019.

## Arquivos do projeto
- script_sql.sql → criação do banco, tabelas, inserts e views

## Como executar
1. Abrir MySQL Workbench ou phpMyAdmin
2. Executar o arquivo script_sql.sql
3. Executar as views criadas

## Views criadas
- total por estado
- média de idade
- escolaridade
- estado civil
- relatório consolidado
